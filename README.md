# PA1 Task Manager

**Author:** Benjamin Dickert

## Description

This is a simple task manager form using HTML, CSS, and JavaScript.
Tasks added are kept in the order they were created, with an creation index ID number for added clarity.

## Features

- Add tasks with a name and priority level
- Low, Medium, and High priority options
- Mark tasks as completed or Undo the completion of a task
- Delete tasks to clear from list entirely
- Completed tasks are visually distinguished from incomplete tasks
- Button colors change based on the current task state
- Empty task submissions are rejected
- After successfully adding a task, the input box clears and automatically regains focus for faster task entry

## How to Run

1. Download or clone the repository.
2. Open `index.html` in your web browser of choice.
3. Enter a task name, select a priority, and press the 'Add Task' button or 'Enter' key.

No additional software or dependencies are required to run the application.
